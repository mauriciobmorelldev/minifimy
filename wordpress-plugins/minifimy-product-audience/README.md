# Minifimy - Público de producto

Agrega en **WooCommerce > Productos > Editar > Datos del producto > General** el bloque **Público MiniFimy**.

- Se pueden marcar Bebés, Niñas y Niños.
- Se admite más de una opción para prendas compartidas.
- Sin selección, el producto mantiene la clasificación actual por talle.
- La categoría original no se modifica.

Instalar el ZIP desde **Plugins > Añadir plugin > Subir plugin** y activarlo.
