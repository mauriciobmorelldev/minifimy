# Plugins de WordPress para MiniFimy

Los dos plugins se complementan:

1. **Minifimy - Padres adicionales de categorías** decide en qué secciones del menú aparece cada subcategoría.
2. **Minifimy - Público de producto** decide qué productos compartidos se ven dentro de cada sección.

Ejemplo: **Partes de abajo** mantiene una sola categoría, aparece en **Niñas** y **Niños**, y cada producto se separa con el público correspondiente.

Ambos plugins son compatibles con productos sin configuración: las categorías mantienen su jerarquía original y los productos siguen usando la clasificación por talle.
